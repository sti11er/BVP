# Решение краевых задач ОДУ методом продолжения по параметру

Программный комплекс для численного решения систем нелинейных обыкновенных дифференциальных уравнений (ОДУ) с краевыми условиями. Основной метод — **параметрическое продолжение (гомотопия)**, который позволяет находить решения в условиях, когда стандартный метод стрельбы не сходится из-за чувствительности к начальному приближению.

## Что решает программа

Программа находит вектор начальных условий $p = x(a)$, при которых решение системы ОДУ $\frac{dx}{dt} = f(t, x)$ на интервале $[a, b]$ удовлетворяет краевым условиям $R(x(a), x(b)) = 0$.

В отличие от задачи Коши, где все начальные данные известны, здесь часть данных задана на правом конце или в виде связей. Программа «дотягивает» произвольное начальное предположение до истинного решения через деформацию задачи.

## Архитектура и алгоритм

### 1. Метод гомотопии (продолжения по параметру)
Программа вводит параметр $\mu \in [0, 1]$ и строит семейство задач:
$$\Psi(p, \mu) = \Phi(p) - (1-\mu)\Phi(p_0) = 0$$
* При $\mu = 0$ решением является начальное предположение пользователя $p_0$.
* При $\mu = 1$ задача совпадает с исходной краевой задачей.
* Программа проходит путь от $\mu=0$ до $\mu=1$ небольшими шагами.

### 2. Схема «Предиктор — Корректор»
На каждом шаге по $\mu$:
* **Предиктор:** Программа вычисляет касательный вектор к траектории решения $\frac{dp}{d\mu}$ и делает «прогноз» следующего значения $p$.
* **Корректор:** Предсказанное значение уточняется с помощью итерационных методов (используется `scipy.optimize.root`). Это гарантирует, что на каждом этапе мы остаемся на линии решения.

### 3. Расширенная система и матрица чувствительности
Для работы корректора необходим точный Якобиан. Программа не просто интегрирует исходную систему из $n$ уравнений, она решает **расширенную систему** размерности $n + n^2$:
* **Состояние:** $\frac{dx}{dt} = f(t, x)$
* **Чувствительность:** $\frac{dX}{dt} = A(t, x)X$, где $X(t) = \frac{\partial x(t)}{\partial p}$ — матрица производных решения по начальному вектору.
Это позволяет получать производные невязки по параметрам стрельбы аналитически точно, что резко повышает стабильность сходимости.

## Техническая реализация

### Вычислительное ядро
* **Динамический парсинг:** Уравнения вводятся пользователем как текст. Программа использует `re` для трансформации индексов (например, `x1` -> `x[0]`) и `compile/eval` для превращения строк в быстрый байт-код Python.
* **Интегрирование:** Используется `scipy.integrate.solve_ivp` (методы RK45, Radau, BDF и др.).
* **Поиск корней:** Библиотека `scipy.optimize.root` с поддержкой методов `hybr`, `lm`, `krylov`.

### Интерфейс (PySide6)
* **Main Window:** Табличный ввод уравнений и условий, настройка параметров сетки и точности.
* **Results Window:** Отдельный аналитический модуль. Позволяет строить графики любых зависимостей (например, $x_2$ от $x_1$ для фазовых портретов) и задавать формулы для осей прямо в GUI.
* **Интегратор:** Модуль на базе `scipy.integrate.quad`, позволяющий вычислить определенный интеграл от любой компоненты полученного решения.

## Запуск и использование

### Требования
* Python 3.10+
* Библиотеки: `numpy`, `scipy`, `matplotlib`, `pyside6`

### Установка
```bash
pip install numpy scipy matplotlib PySide6
```

### Старт
```bash
python main.py
```
